# Збирач повідомлень з чатів (TP Spain)

Невеликий застосунок для вашого компʼютера. Ви додаєте групи Telegram, у яких
ви учасник (або окремі теми в них), і він збирає текст повідомлень за останні
6–72 години — навіть там, де адміни заборонили експорт.

- Читає від вашого акаунта, як звичайний Telegram.
- Зберігає лише **дату, текст і посилання** — без імен, телефонів, фото.
- Працює тільки на цьому компʼютері (сторінка на `127.0.0.1`, ззовні недоступна).
- Усе зберігається в папці `~/.tpspain-collector`: налаштування, зібрані
  файли (`exports/`) і вхід у Telegram (`session.session`).
  **Файл сесії — це вхід у ваш акаунт. Нікому його не надсилайте.**

## Запуск

**macOS:** двічі клацніть `run.command`. Якщо macOS не дає відкрити —
клацніть правою кнопкою → «Відкрити» → «Відкрити». Перший запуск встановлює
потрібне (~1 хв). Якщо попросить встановити Python або «інструменти
командного рядка» — погодьтесь.

**Windows:** двічі клацніть `run.bat` (потрібен Python з python.org).

Відкриється сторінка в браузері. Щоб зупинити — закрийте вікно Терміналу.

## Перший раз

1. **Ключ Telegram:** my.telegram.org → «API development tools» → створіть
   застосунок (назва будь-яка) → скопіюйте `api_id` і `api_hash` у застосунок.
2. **Вхід:** номер телефону → код, що прийде в Telegram → (якщо є) пароль
   двоетапної перевірки.

## Користування

- **Додати групу:** «Мої групи…» → «Додати», або вставте посилання:
  `t.me/spain_useful` — уся група, `t.me/spain_useful/74767` — лише тема.
- **Сканувати:** оберіть період і натисніть «Сканувати». Галочка «лише про
  документи…» відсіює балачки.
- **Далі:** «Копіювати все» або «Зберегти файл» — і надішліть це для
  оновлень на сайті й у каналі.
